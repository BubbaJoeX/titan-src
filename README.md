# SWG: Bubba Joe's Flavor

This repository and its sibling repositories (`client`, `dsrc`) contain internal tooling and development for **Bubba Joe's flavor of Star Wars Galaxies**. No support or assistance will be given.

Code is provided as/is and may be updated at any moment. Many features from these repositories may be missing contents from other repositories.
